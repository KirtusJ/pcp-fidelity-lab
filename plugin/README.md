# PCP Fidelity Audit Lab (0.1.0; experimental)

**Research-only, private skills plugin.** The governing PCP Core R13 and Mathematics R5, Science R11, Engineering R7, Cryptography R8 appear as source snapshots, with Core conditional attachments. Statistics 1.0 and QA 1.0 are *proposed, not adopted* source snapshots. Plugin availability is not a mandate or grant.

The source text remains exactly what was supplied in the user attachments; the plugin's skill is a new research delivery wrapper, **not a replacement PCP normative specification**. A source digest authenticates neither its creator nor its truth. The host must invoke the skill and genuinely inspect the relevant source before claiming to apply it. There is no runtime service, MCP server, automatic installation into other LLMs, new PCP command language, or effect authorization.

**Authorship:** Original PCP research direction and protocol authorship: Kirtus Justus. Experimental plugin packaging and evaluation notes: ChatGPT (OpenAI), internal research provenance, not independent validation.

The strongest intended trial compares how PCP-fidelity tasks perform when given identical information via a ZIP, this skills plugin, or an independently implemented runtime service, with a competent ordinary-work baseline. This trial has not been run.
